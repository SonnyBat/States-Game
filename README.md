# US State Guessing Game

A **US State Guessing Game** built in Python using `turtle` and `pandas`.

I made this project to practice using **Pandas for the first time**, working with **CSV files**, and getting more comfortable combining different Python modules into a small interactive game.

## 🎮 Features

* 🇺🇸 Guess all 50 US states
* 🗺️ State names appear on the map when guessed correctly
* 🏆 Score tracking based on how many states you've guessed
* 🐼 Uses `pandas` to read and work with the CSV data
* 🐢 Built with Python's `turtle` module
* 🎉 The game ends once all 50 states have been guessed

## 🚀 How to Run

First, make sure you have **Python** installed and install the `pandas` module:

```bash
pip install pandas
```

Then make sure all three files are in the **same folder**:

```text
50_states.csv
blank_states_img.gif
main.py
```

Finally, run:

```bash
python main.py
```

That's it! The map should launch and you can start guessing the states.
